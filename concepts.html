Key Web Server Concepts

Concept Description
HTTP The protocol used for communication between web browsers and servers.
Web Server Software that processes requests and delivers web content.
Load Balancing Distributing traffic across multiple servers to improve performance.
Reverse Proxy A server that forwards client requests to backend servers.
CDN A content delivery network that speeds up websites by serving cached content.
HTTPS Secure version of HTTP that encrypts data using SSL/TLS.
DNS Translates domain names (like google.com) into IP addresses.
IP Address A unique identifier for devices on a network.
Port A communication endpoint (e.g., HTTP uses port 80, HTTPS uses 443).
Firewall Security system that controls incoming and outgoing traffic.
Cloud Computing Using remote servers to host and manage data instead of local machines.
Scalability Ability of a system to handle increased traffic or workload.
Latency The delay before data begins transferring.
